# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues or discussions. If private vulnerability reporting is enabled for this repository, use GitHub's **Report a vulnerability** option. Otherwise, contact the repository owner privately through a verified channel listed on their GitHub profile.

Include the affected component, steps to reproduce, and potential impact. Do not include real credentials, private webhook URLs, or other users' data.

## Scope and security notes

The extension runs on GitHub repository pages and can make HTTPS requests for user-triggered API widgets. Active previews use sandboxed iframes and a restrictive Content Security Policy. See the README for the current security and privacy behavior.
