GHBuilt for GitHub

GitHub README Widgets

Interactive code and API widgets, built to run directly inside GitHub repository READMEs.

Extension language

Choose the language used by the dashboard and widgets on GitHub.

Discord webhook

Save a webhook to manually send a widget's code and latest result to your Discord channel.

The URL is stored locally and used only when you click “Send to Discord.” Treat it like a password.

Widget gallery

The code-block language selects the widget rendered on GitHub.

APIAPI request

Sends an HTTPS request and displays its HTTP status and response.

```api-request GET https://api.github.com ```

UPAPI status

Checks an HTTPS endpoint and displays its health as a status badge.

```api-status {"url":"https://api.github.com"} ```

▥API chart

Visualizes numeric values from JSON configuration, optionally using live data.

```api-chart {"title":"Requests","labels":["OK","Fehler"],"values":[84,6]} ```

▤API tabs

Splits a text block into selectable tabs using Markdown headings.

```api-tabs ## Übersicht Text zur Übersicht ## Details Weitere Informationen ```

HTMLHTML live preview

Runs HTML, CSS, and JavaScript in a sandboxed iframe using the github-live-preview marker.

```html <!-- github-live-preview --> <h1>Hello from a sandbox</h1> ```

</>Live code editor

Edit HTML or JavaScript and run it inside the isolated preview.

```code-editor <h1>Editable preview</h1> ```

C#C# / .NET playground

Run C# locally in a sandboxed .NET WebAssembly runtime. Execution is opt-in and requires the marker.

```csharp // github-dotnet-run using System; Console.WriteLine("Hello from .NET"); ```
