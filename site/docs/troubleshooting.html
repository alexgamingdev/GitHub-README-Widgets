Troubleshooting

No widget appears

  • Confirm the extension is enabled and was loaded from the expected dist/chromium or dist/firefox folder.
  • Reload the GitHub repository page after installing or reloading the extension.
  • Check that the code fence uses a supported language such as api-status, api-chart, api-tabs, html-live, or code-editor.
  • For API requests, put the HTTP method and HTTPS URL together on a line of their own.
  • Confirm the page is on github.com, not a third-party GitHub mirror.

An API request fails

  • Check that the URL is HTTPS and has no embedded credentials.
  • Check whether the endpoint is reachable without cookies or custom headers. The widget cannot supply either.
  • The endpoint must not redirect; the extension rejects redirects.
  • Check the endpoint's response and CORS behavior in the browser. Requests have a 15-second timeout.
  • Some APIs require authentication or a request body and cannot be called by this widget format.

JSON configuration is invalid

Use valid JSON with double-quoted property names and string values. For charts, labels and numeric values must have the same number of entries.

A live preview is blank or incomplete

External scripts, images, fonts, frames, and network requests are blocked by design. Inline HTML, CSS, and JavaScript are supported. Run the preview explicitly after making changes.

C# / .NET does not start

  • Make sure the code fence is a supported C# language and its first line is // github-dotnet-run.
  • Build the package again with npm ci and npm run build so the bundled runtime exists under vendor/blazor-wasm/.
  • Reload the unpacked extension and then reload the GitHub page.

Still stuck?

Open a GitHub issue with browser/version, steps to reproduce, and the expected and actual behavior. Do not include webhook URLs, access tokens, or private repository content.
