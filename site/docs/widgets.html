Widget reference

Widgets are detected from a supported fenced-code language or from an API request line. They appear only when the extension is active on a GitHub repository page.

API request

Use a supported HTTP method followed by an HTTPS URL on its own line. Methods: GET, HEAD, POST, PUT, PATCH, DELETE, and OPTIONS. The extension does not provide custom headers or a request body.

```http
GET https://api.github.com
```

API status

Use a JSON object with a required url and optional method, label, and statusPath. The default status path is status.

```api-status
{"url":"https://api.github.com","label":"GitHub API","statusPath":"status"}
```

Values such as operational, ok, and up are recognized as healthy; down, error, and degraded are recognized as unhealthy.

API chart

Provide equal-length labels and numeric values arrays. An optional title labels the chart. Add a url and optional method to reload data when the user runs the widget.

```api-chart
{"title":"Weekly signups","labels":["Mon","Tue","Wed"],"values":[12,18,15]}
```

Markdown tabs

Each level-two heading (##) starts a tab. Tab contents are rendered as text, not HTML.

```api-tabs
## JavaScript
JavaScript example

## TypeScript
TypeScript example
```

Live HTML preview

Use an html-live fenced block, or include the <!-- github-live-preview --> marker in a code block. The preview loads only after an explicit user action.

```html-live
<button id="hello">Click me</button>
<script>
  document.querySelector("#hello").addEventListener("click", (event) => {
    event.currentTarget.textContent = "Hello!";
  });
</script>
```

Code editor

Use a code-editor fenced block for editable HTML or JavaScript. Changes run in the isolated preview only when the user chooses Run.

C# / .NET

Use a csharp, cs, dotnet-run, csharp-run, or cs-run block and put // github-dotnet-run on its first line to run it. Other C# blocks remain ordinary code. The bundled compiler and runtime are loaded locally from the extension package.

```csharp
// github-dotnet-run
using System;

Console.WriteLine("Hello from .NET WebAssembly");
```

Limits

  • Live HTML, editor, and .NET code blocks are limited to 100,000 characters.
  • API response output is truncated at 100,000 characters.
  • API requests have a 15-second timeout.
  • API requests send no cookies, custom headers, or request body, and do not follow redirects.
