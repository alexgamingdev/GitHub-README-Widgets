Installation and build

Build the extension locally to try changes or load an unpacked development package. A permanent Firefox release must be signed by Mozilla Add-ons.

Requirements

  • Node.js 20 or later
  • npm

Build the packages

npm ci
npm run build

The build creates dist/chromium and dist/firefox. Make source changes in extensions/chromium or extensions/firefox; generated packages are not the source of truth.

Chromium browsers

  1. Open chrome://extensions, edge://extensions, or the browser's equivalent extension management page.
  2. Enable Developer mode.
  3. Choose Load unpacked and select the project's dist/chromium folder.
  4. Open or reload a GitHub repository page with a supported widget block.

Firefox

  1. Open about:debugging#/runtime/this-firefox.
  2. Choose Load Temporary Add-on….
  3. Select dist/firefox/manifest.json.
  4. Open or reload a GitHub repository page with a supported widget block.

Firefox removes temporary add-ons when the browser closes. For a permanent installation, submit and sign the extension through Mozilla Add-ons.

Update after source changes

Run npm run build again, then use the extension manager's reload action for the unpacked add-on. Reload the GitHub page to apply content-script changes.
