Security and privacy

Review browser permission prompts and only run code or make requests to endpoints you trust. Widgets are executable content, not static documentation.

Browser permissions

The extension runs its content script on https://github.com/* and requests host access to HTTPS URLs so API widgets can make requests. Browser vendors may present this as broad website access. API requests are made only when a widget is explicitly run.

API requests

  • Only HTTPS URLs without embedded username or password are accepted.
  • The extension sends no cookies, custom headers, or request body.
  • Redirects are rejected and requests time out after 15 seconds.
  • Responses are displayed in the widget and truncated at 100,000 characters.

HTML and JavaScript previews

Previews run in an iframe with sandboxed scripts and a restrictive Content Security Policy. Network connections, external frames, forms, and external resources are blocked. The preview has no access to the GitHub page DOM or extension APIs. It starts only when you choose to run it.

C# / .NET execution

Marked C# code runs in a separate sandboxed iframe using the compiler and .NET WebAssembly runtime included in the extension package. It does not have network access; only the extension package's runtime resources are allowed.

Discord webhook

A webhook URL that you save is kept in local browser extension storage. The extension sends widget code and its latest result only when you explicitly choose the Discord share action. Treat webhook URLs as secrets; anyone who has one may be able to post to its channel.

Reporting a vulnerability

Do not post exploit details, private URLs, or credentials in a public issue. Follow the private reporting instructions in the repository's security policy.
