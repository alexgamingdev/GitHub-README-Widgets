A browser extension for GitHub

Make repository READMEs interactive.

GitHub README Widgets turns supported code blocks into API tools, charts, tabs, and sandboxed code previews—right in your browser.

Get started Read the docs Explore features

Widgets for useful README content

Keep examples close to your project documentation. Widgets run locally in the browser when you visit a GitHub repository page; they do not change the README or GitHub's rendering for other visitors.

API requests and status

Run HTTPS API requests, display service health, and visualize JSON chart data on demand.

Tabs and live previews

Organize Markdown with tabs and interact with HTML, CSS, and JavaScript previews.

Local code execution

Edit examples in a local editor or run explicitly marked C# with the bundled .NET WebAssembly runtime.

Try it locally

  1. Install Node.js 20 or later.
  2. Run npm ci, then npm run build in the project directory.
  3. Load dist/chromium as an unpacked extension, or load dist/firefox/manifest.json as a temporary Firefox add-on.
  4. Visit a GitHub repository with a supported widget code block.

Designed with isolation in mind

Live previews run in sandboxed iframes with a restrictive Content Security Policy. API widgets can make HTTPS requests when used, while the extension does not send cookies or follow redirects. Review the browser permissions and the project's license before installing or redistributing it.
